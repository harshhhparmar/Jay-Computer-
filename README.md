# 🖥️ Jay Computer | Digital Seva Kendra

Welcome to the **Jay Computer** official web portal! Your one-stop digital solution for all government services, document applications, and digital assistance in Halvad, Gujarat.

## 🌟 What We Do

We make government and online services simple, fast, and accessible for everyone. 

- 📜 **Certificates & Documents:** Income, Caste, Domicile, EWS, Ration Card, Voter ID, PAN Card.
- 🎓 **Scholarships:** Digital Gujarat Scholarship, E-Nirman Scholarship, RTE Admission.
- 🏥 **Health & Welfare:** Ayushman Bharat Card, E-Shram Card, PM Kisan, Vidhva Sahay, Manav Kalyan Yojana.
- 🛡️ **Insurance & Finance:** LIC Premium/New Policy, Vehicle Insurance, Personal Loans.
- 🏢 **Business & More:** MSME Udyam, Income Tax Returns, Driving License, and more!

## 🚀 Features

- 📱 **Mobile Friendly:** Browse seamlessly on any device.
- 💬 **WhatsApp Integration:** Apply or inquire about services directly via WhatsApp with just a click.
- 📄 **Detailed Requirements:** Transparent document checklists provided in both English and Gujarati.
- ⚡ **Fast & Secure:** Built with modern technologies (React, Vite, Tailwind CSS) for a blazing fast experience.

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, TypeScript
- **Styling:** Tailwind CSS, Lucide Icons, Framer Motion (Animations)
- **Routing:** React Router DOM
